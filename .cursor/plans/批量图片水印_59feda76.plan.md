# 新增批量图片水印

## 实现
- 修改 [`tabs/tab_process.py`](tabs/tab_process.py)，在“组合贴入…”正下方注册“加水印…”工具行，并补充用途说明。
- 新增一个模态参数对话框，一次设置字号、透明度、倾斜角度、横向间距和行间距；提供白色半透明、约 35° 向右下倾斜的合理默认值，并在确认时校验数值范围。
- 新增纯图片处理函数：加载可缩放的粗体字体，在覆盖图片边界的透明 RGBA 大画布上按多行多列重复绘制 `ALEXCARD`，旋转后与原图合成，确保从左上到右下均匀铺满且边角不留明显空白。
- 复用现有多选图片、输出目录、原格式保存和批量报告流程；输出命名为 `<原文件名>_watermarked.<原扩展名>`，JPEG 合成后转为 RGB，PNG/WebP 保留透明通道，并逐张隔离异常，最终在报告区及完成弹窗显示成功/失败数量。

## 验证
- 对 [`tabs/tab_process.py`](tabs/tab_process.py) 执行编译与诊断检查。
- 使用临时横图、竖图、方图及 JPEG/PNG/WebP 验证：水印文字、透明度、角度、行列密度、四角覆盖、输出后缀、原图不被覆盖及失败报告。
- 启动应用确认按钮位置、参数对话框校验、取消流程、目录选择及批量完成提示正常。
