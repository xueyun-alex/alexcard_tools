# 海报双图贴入

## 流程

```mermaid
flowchart LR
  pickPoster[选海报] --> boxSelect[Canvas框选两框]
  boxSelect --> pickImgs[选图片或文件夹]
  pickImgs --> pair[upload_pairs配对]
  pair --> compose[每组cover贴入]
  compose --> save[海报同目录保存]
```

1. 选一张海报模板  
2. 弹窗预览，依次拖出两个矩形（位置1 / 位置2）  
3. 多选图片或选文件夹  
4. 复用现有 [`upload_pairs`](d:\code\alexcard_tools\main.py)：纯数字 stem（`1`、`2`…）→ 位置1；其余（`1-1`、`2-2`…）按名排序 → 位置2  
5. 每组复制海报，两图 **cover**（等比裁中、填满框）贴入两框，保存到**海报所在目录**

## UI（[`main.py`](d:\code\alexcard_tools\main.py)）

在「图片处理」Tab 增加一行（同 `_add_tool_row`）：

- 按钮：`海报双图贴入…`
- 说明：框选海报两个位置；主图 `1/2/3…` 进位置1，副图 `1-1/2-2…` 进位置2；输出到海报同目录

`App.on_poster_compose` 顺序：

1. `askopenfilename` 选海报  
2. `ask_poster_regions(parent, poster_path)` → `((x1,y1,x2,y2), (x1,y1,x2,y2))` 或取消  
3. 多选图 / 或目录（`list_images_in_dir`）  
4. `upload_pairs`；失败则 `messagebox.showerror`  
5. `build_poster_compose_report(...)` → 报告区 + 成功/失败弹窗  

## 框选对话框

新建 `ask_poster_regions`（`Toplevel` + `grab_set`）：

- Pillow 打开海报，缩放到适合窗口（长边约 900px），Canvas 显示  
- 鼠标拖拽画矩形；确认后收第 1 框，再收第 2 框  
- 提示文案区分「请框选位置1 / 位置2」  
- 「撤销当前框 / 取消」  
- 显示坐标按 `scale` 映射回原图像素，存为正矩形 `(left, top, right, bottom)`  
- 框宽高至少数像素才有效  

## 合成与保存

纯函数（与亮度/转 JPG 同风格）：

| 函数 | 作用 |
|------|------|
| `fit_cover(im, box_w, box_h)` | 等比放大后居中裁切到目标尺寸 |
| `paste_into_poster(poster, img, box)` | 打开/拷贝海报，cover 后 `paste` 到 box |
| `compose_poster_pair(poster_path, img1, img2, box1, box2, dest)` | 处理一组并保存 |
| `poster_compose_output_path(poster_path, index)` | `{dir}/{stem}_{index}{ext}`（index 从 1） |
| `build_poster_compose_report(...)` | 批量；返回 report / ok / fail |

实现要点：

- 每组 `Image.open(poster).copy()`，避免改到原海报文件  
- 原图有 alpha 时用 mask paste  
- JPEG 海报则贴入前转 RGB（复用 `prepare_for_jpeg` 思路）  
- 输出扩展名与海报一致，走现有 `save_image`  
- 若目标已存在则覆盖（与同目录保存习惯一致）

配对与位置对应（与闲管家一致）：

- 组内第 1 张（主图）→ 框 1  
- 组内第 2 张（副图）→ 框 2
