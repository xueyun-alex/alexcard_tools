# 闲管家 · 批量上线表单增强

## 范围（你选的 2A）

在已有 [`ask_batch_publish_dialog`](d:\code\alexcard_tools\main.py) / [`BatchPublishParams`](d:\code\alexcard_tools\main.py) 上迭代：

- 新增必填字段 **商品规格**（属性名，如 `品相`），放在 **规格名称** 上方
- **规格名称** 不变：`PSA10|BGS9.5|裸卡`（`|` 分隔）
- 图片输入改为：**本地文件夹路径**（`Entry` +「浏览…」选目录），不再多选文件
- 从该目录枚举图片（扩展名对齐现有 `IMAGE_FILETYPES`），按文件名排序；校验目录内存在 `文案汇总.txt`
- 报告区写明上传策略：**按序每次 2 张依次上传**（仅记录，不调 Playwright）
- **不做**网页自动上传

## 字段顺序

1. 商品分类  
2. **商品规格**（新）  
3. 规格名称（旁注：多个用 `|` 分隔）  
4. 运费  
5. 图片目录（路径 + 浏览）

## 数据结构

扩展 `BatchPublishParams`：

- `spec_attr: str` — 商品规格（如 `品相`）
- `specs: list[str]` — 规格名称拆分结果  
- `image_dir: str` — 用户填写的文件夹  
- `image_paths: list[str]` — 目录内排序后的图片绝对路径  
- 保留 `category` / `shipping` / `copy_txt`

## 目录与配对逻辑

- `list_images_in_dir(dir_path) -> list[str]`：扫目录（不递归），匹配常见图片后缀，自然/字典序排序
- `upload_pairs(paths) -> list[tuple[str, ...]]`：按序两两分组；奇数最后一组只含 1 张
- 文案路径：`os.path.join(image_dir, BATCH_TXT_NAME)`（目录模式不再经 `batch_txt_path(多文件)`）
- 校验：目录存在、至少 1 张图、`文案汇总.txt` 存在、商品规格非空

## 报告区示例

```text
—— 批量上线（仅记录）——

商品规格：品相

图片目录：D:\...\xxx（12 张，上传按序每次 2 张，共 6 组）
文案：D:\...\xxx\文案汇总.txt
```
